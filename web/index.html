    OPTIONAL NEXT STEP

    Windows VM testing

    VM host not connected

    Dynamic execution is not enabled here.

    This scanner has no VM host configured and will never launch repository files. For deeper analysis, use a disposable Windows VM or Windows Sandbox that you control.

    Windows Sandbox safety guidance

    Before any manual test

    • 1 Take a clean VM snapshot; use no real accounts or secrets.
    • 2 Disable shared folders, clipboard, and network access.
    • 3 Revert the VM snapshot after the investigation.
